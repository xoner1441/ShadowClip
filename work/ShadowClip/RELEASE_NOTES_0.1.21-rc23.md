# ShadowClip 0.1.21-rc23

- Redesigned Capture, Video, Audio, HUD, Storage, Updates, Logs, and Hotkeys to match the modern Home and Clips dashboard.
- Added consistent dark entries, selectors, number controls, grouped settings panels, and page-level Save changes actions.
- Added a live unsaved-changes indicator across settings pages.
- Added mouse-wheel scrolling across the complete Storage page at smaller window sizes.
- Restored clear access to storage limits, game/app folders, replay reset, and HUD gallery size in their matching settings pages.
- Changed gallery deletion to move media into the Windows Recycle Bin instead of permanently deleting it.
- Added a HUD test-notification action and clearer descriptions for capture, bitrate, audio synchronization, startup, and profiles.
