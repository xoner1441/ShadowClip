# ShadowClip 0.1.21-rc22

- Added a complete in-app clip library with real video thumbnails.
- Added search, game/app filtering, replay/recording filtering, and date/name/size sorting.
- Added direct open, reveal, rename, and delete actions for saved media.
- Added incremental card loading and sequential background thumbnail generation for responsive large libraries.
- Fixed media discovery after restart for OBS `Replay ...` files and date-named recordings.
- Updated automatic storage cleanup to include all supported OBS and FFmpeg media names.
- Fixed back-to-back gallery refreshes after rapid rename/delete operations.
