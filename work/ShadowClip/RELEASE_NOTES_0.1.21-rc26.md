# ShadowClip 0.1.21-rc26

- Added centralized friendly names for popular games, launch processes, browsers, new clip folders, gallery filters, per-game profile labels, and diagnostics.
- Existing process-named gallery folders such as `javaw`, `RustClient`, and `FortniteClient-Win64-Shipping` now display as Minecraft, Rust, and Fortnite without moving old media.
- Replaced the setup-check message box with a scrollable in-app report.
- Added contextual one-click repairs for automatic bitrate and replay RAM, encoder detection, bundled FFmpeg/OBS paths, audio scans, primary-monitor capture, and replay start/restart.
- Added a stable anonymous beta Support ID with copy action on the Updates page.
- Beta diagnostic ZIPs now include health summaries and the latest capture-test result while redacting Windows user/computer names, window titles, and personal path roots.
- Made the expanded Updates page fully mouse-wheel scrollable at the minimum window size.
