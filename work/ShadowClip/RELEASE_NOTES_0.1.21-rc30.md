# ShadowClip 0.1.21-rc30

- Made the Replay status card in the upper-left Home dashboard directly clickable.
- Clicking the card, icon, title, value, or action text uses the same replay toggle path as the hotkey, tray, and HUD.
- Added a hand cursor, accent-border hover state, and panel hover color to clearly identify the card as interactive.
- Added keyboard activation through Enter and Space when the card has focus.
- The card action changes between `Start` and `Stop` with the live replay state.
- Kept the compact action text within the minimum supported window width.
