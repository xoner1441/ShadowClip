# ShadowClip 0.1.21-rc11

- Added `Check Setup` to validate FFmpeg, OBS runtime, hardware encoder selection, replay state, audio devices, output-folder write access, capture source, and OBS replay RAM sizing.
- Added `Export Debug Report`, which writes a ZIP with redacted settings, health-check results, UI log text, and recent ShadowClip runtime logs.
- Added the same diagnostics actions to the HUD settings view for easier tester support.
- Kept OBS replay RAM auto mode from rc10 as the default installer setting.
